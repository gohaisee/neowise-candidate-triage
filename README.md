# Входящие заявки

Менеджер вводит текст заявки и получает тему и черновик ответа. Если модель не ответила или ответ непригоден, на экране ручной разбор, а старый черновик стирается.

Нужен Node.js 20 или новее.

```sh
node server.mjs
```

Откройте http://127.0.0.1:3000. Порт можно задать через переменную `PORT`.

```sh
node --test
```

## Как проверить

1. Введи `где доставка заказа` и нажми «Разобрать заявку» или Enter. Появятся тема «Доставка» и черновик.
2. Замени текст на `[bad-topic] верните деньги` и отправь снова. Черновик исчезнет, останется «Разберите заявку вручную. Черновик очищен.»
3. Сотри поле и отправь пустым. Будет «Введите текст заявки.», старого черновика нет.
4. Для остальных сбоев подставь `[timeout]`, `[error]`, `[bad-json]` или `[empty-draft]`. Все они ведут в ручной разбор. Обычные «какая цена» и «хочу поговорить» дают «Цена» и «Другое».

Shift+Enter в поле переносит строку.
